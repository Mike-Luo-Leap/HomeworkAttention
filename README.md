# 作业板

基于 Tauri 2、TypeScript 和 Vite 的 Windows 作业板，界面采用 WinUI 风格。

## 开发与构建

```powershell
npm install
npm run tauri dev
npm run tauri build
```

Windows 桌面构建需要安装带有 MSVC C++ 工具链的 Visual Studio Build Tools。

## 使用

- 作业板固定在桌面底层、只显示系统托盘图标，不显示任务栏按钮。点右上角锁切换为可移动状态；解锁时界面蒙灰并显示移动指引，暂停作业编辑。
- 主板为每个科目显示一张作业卡片。点卡片编辑该科目作业；底部“布置”用于为尚未布置作业的科目创建作业。
- 科目卡片使用固定宽度排列；底部 A− / A+ 可调整科目名称和作业预览字号。
- 桌面版的作业编辑和设置分别打开独立原生窗口，保存后主板自动同步刷新；浏览器预览使用页面内弹窗。
- 首次启动不会生成示例作业；作业板从空白状态开始。
- 作业编辑支持加粗、斜体、下划线、文字颜色；每个项目符号行保存为一条作业。
- 过期时间表示交作业的时间，作业在所选日期零点过期；最早只能设置为明天。同一科目的作业共用编辑器中的过期日期，每条记录仍单独保存 `DueAt`，便于以后扩展。
- 过期作业不显示在首页，可从底部“查看过期的作业”按科目查看和编辑；启动时会清理到期日早于昨天的记录，因此过期作业至少保留一天。编辑时过期日不能早于今天。
- 右上角图片按钮下载 PNG；快捷导出按钮将 PNG 保存到设置的目录，路径留空则使用系统“图片”目录。
- 设置页目前提供“基本”、“科目”和“标签”三页。

## 数据文件

Tauri 运行时会在系统为应用分配的配置目录中创建：

- `Settings.json`：以 `Pages.Basic`、`Pages.Subjects` 为键分别存储页面设置。
- `Homework.json`：以每条作业的 UUID 为键保存记录，记录包含科目 UUID、富文本内容、过期时间及创建/更新时间。

在普通浏览器中运行开发服务器时，数据暂存于浏览器 `localStorage`；桌面应用则使用上述 JSON 文件。

右上角“-”会将作业板隐藏到系统托盘；菜单中的“关闭并保存应用”会先写入配置，再退出进程。从托盘菜单可以重新显示作业板或退出应用。

## JSON 文件位置与格式

桌面应用首次启动时，会在应用程序所在文件夹自动创建两个文件，即与 `.exe` 同目录：

```text
应用程序文件夹\Settings.json
应用程序文件夹\Homework.json
```

如果旧版本文件还在 Tauri 的应用配置目录中，应用会在新位置没有对应文件时自动迁移它；不会覆盖应用文件夹中已经存在的数据。只运行 `npm run dev` 浏览器版时仍使用浏览器 `localStorage`，不会生成这两个文件。

`Settings.json` 按页面分区保存，例如：

```json
{
  "Pages": {
    "Basic": {
      "alwaysOnBottom": true,
      "windowTitle": "作业",
      "zoom": 100,
      "contentScale": 110,
      "quickExportPath": ""
    },
    "Subjects": {
      "items": [
        {
          "Id": "科目 UUID",
          "Name": "语文",
          "QuickFields": []
        }
      ]
    },
    "Tags": {
      "items": [
        { "Id": "标签 UUID", "Name": "不交", "Color": "#2196F3" },
        { "Id": "标签 UUID", "Name": "中午作业", "Color": "#2196F3" }
      ]
    }
  }
}
```

每个科目的 `QuickFields` 是该科目专属的编辑快捷字段；在编辑作业时点击字段，会将文字插入当前光标位置。
新安装默认提供语文、数学、英语、物理、化学、政治、历史、地理、生物和其他十个科目，默认不带科目快捷字段。编辑器数字键盘下方另有“课、例、变、T、P”五个固定快捷文本，同样插入当前光标位置。
`Tags.items` 是全局作业标签设置。标签 ID 用于在 `Homework.json` 的每条作业 `Tags` 数组中保存选中状态，标签名称和颜色可在设置的“标签”页调整。编辑时，标签按钮与科目快捷文本并排显示，用于切换当前作业行的标签；首页会在对应作业内容旁显示已选标签。

`Homework.json` 是以作业 UUID 为键的对象。首次启动为空对象 `{}`；保存作业后，每条作业单独包含自己的 `DueAt`，后续可扩展为不同作业使用不同过期时间：

```json
{
  "作业 UUID": {
    "Id": "作业 UUID",
    "SubjectId": "所属科目 UUID",
    "ContentHtml": "复习 <b>课文</b>",
    "DueAt": "2026-10-04",
    "CreatedAt": "2026-10-03T12:00:00.000Z",
    "UpdatedAt": "2026-10-03T12:00:00.000Z",
    "Tags": ["标签 UUID"]
  }
}
```
